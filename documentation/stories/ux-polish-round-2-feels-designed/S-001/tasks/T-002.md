## Description

DESIGN.md: "Empty state: Display-size heading + muted body + optional action." When a scan completes and finds no duplicates, the contact sheet area is blank. Show a centered empty state.

## Files to modify

### `frontend/src/components/ContactSheet.tsx`

In the main `ContactSheet` component (around line 296), where it currently returns `null` for empty sections, replace with an empty state:

Change:
\`\`\`tsx
{sections.length === 0 ? null : (
\`\`\`

To:
\`\`\`tsx
{sections.length === 0 ? (
  <div className="contact-sheet-empty">
    <span className="contact-sheet-empty-icon">✓</span>
    <h2 className="contact-sheet-empty-heading">No duplicates found</h2>
    <p className="contact-sheet-empty-body">
      All files in your selected folders are unique.
    </p>
  </div>
) : (
\`\`\`

Note: this empty state should only show when there ARE groups loaded (scan completed) but the current filter yields zero results. Add a prop or check to distinguish "no scan yet" from "scan found nothing." The ContactSheet receives \`groups\` — if \`groups.length === 0\` AND we're showing the contact sheet (not quarantine view), show the empty state.
