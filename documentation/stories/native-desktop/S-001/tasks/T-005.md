# native-desktop/S-001-T5: Concurrent image decode semaphore in crate:core (2-4 workers)

**Status:** done
**Priority:** P1
**Blocked By:** S-001-T3

## What
Create a module-level semaphore in `crates/core` that bounds concurrent image decoding to 2-4 workers. This controls peak memory during pixel hash computation (each full RGBA decode of a 24MP image ~= 96MB; 4 concurrent = ~384MB peak). Expose it as a shared semaphore that the scanner uses when calling pixel_hash.

## Why
CEO review Section 7 WARNING: 'Bound concurrent image decodes to 2 or add memory-based throttling.' Eng review E8: 'Set concurrent image decode semaphore 2-4 threads.' Without this bound, scanning a folder with many large images could exhaust RAM.

## Context
Architecture decision E8: semaphore size = min(rayon::current_num_threads(), 4), floor 2. This means on a 10-core Mac you still cap at 4 concurrent decodes.

The semaphore is NOT for I/O (directory walking or file reads) — those use rayon's default pool. It is ONLY for the pixel-hash decode step, which is the memory-intensive operation.

Implementation pattern: use tokio::sync::Semaphore (or std::sync::Arc<tokio::sync::Semaphore>) if async, or a simple Mutex<()> pool if sync rayon. The scanner in T-011 will use this.

Configurable concurrency (T-012) builds on top of this semaphore — this task establishes the default cap.

**Step 2 — Create the semaphore module:**
File: `crates/core/src/decode_semaphore.rs`
```rust
use std::sync::Arc;

/// Global semaphore capping concurrent RGBA image decodes.
/// Each full decode of a 24MP image uses ~96MB; 4 concurrent = ~384MB peak.
/// Eng review E8: cap = min(cpu_count, 4), floor 2.
static DECODE_SEM: std::sync::OnceLock<Arc<tokio::sync::Semaphore>> = std::sync::OnceLock::new();

pub fn semaphore() -> Arc<tokio::sync::Semaphore> {
    DECODE_SEM.get_or_init(|| {
        let cap = (num_cpus::get()).min(4).max(2);
        Arc::new(tokio::sync::Semaphore::new(cap))
    }).clone()
}

pub async fn acquire() -> tokio::sync::SemaphorePermit<'static> {
    semaphore().acquire_owned().await.expect('semaphore closed')
}
```

Add num_cpus to Cargo.toml:
```toml
num_cpus = '1'
```

**Step 3 — Wire up lib.rs:**

mod tests {

    async fn semaphore_cap_is_2_to_4() {
