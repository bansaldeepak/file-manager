# native-desktop/S-001-T24: Group dedup strategy: overlap between exact + pixel-identical groups

**Status:** done
**Priority:** P3
**Blocked By:** —

## What
Design and implement the strategy for files that appear in both an exact-duplicate group AND a pixel-identical group. Decide whether they are shown in both groups, merged into one group, or deduped from the pixel-identical group since exact-match subsumes it. Write tests to verify the chosen strategy produces stable, non-surprising group membership.

## Why
CEO review T23: 'Group deduplication strategy for files appearing in both exact and pixel-identical groups.' Without a defined strategy, a user sees the same file pair in two groups, quarantines it once in the exact group, then sees a 'ghost' in the pixel-identical group pointing to a file that no longer exists. This confuses the review flow and wastes the user's time.

## Context
Background:
- Exact group: files A and B share SHA-256 (byte-identical)
- Pixel group: files B and C share pixel_hash but different SHA-256 (same visual content, different encoding)
- B appears in both groups

Recommended strategy (from TRD discussion): 'Exact subsumes pixel.' If file B is already in an exact group, exclude it from pixel-identical groups. This means:
- Exact groups show only byte-identical duplicates
- Pixel-identical groups show only files NOT already in an exact group
- A file can appear in at most one group

Alternative: show all groups, indicate the group type. The user can decide. This is more complete but more confusing.

This task is P3/deferred — the MVP ships with the 'exact subsumes pixel' strategy and this task either confirms it's implemented or refines it post-ship.

## How

**Step 1 — Update grouper to implement 'exact subsumes pixel' strategy:**
File: `crates/core/src/grouper.rs` (update build_groups)
```rust
pub fn build_groups(files: &[ScannedFile]) -> Vec<DuplicateGroup> {
    let mut sha256_groups: HashMap<Vec<u8>, Vec<usize>> = HashMap::new();
    let mut pixel_groups: HashMap<Vec<u8>, Vec<usize>> = HashMap::new();

    for (i, f) in files.iter().enumerate() {
        if let Some(h) = &f.sha256 {
            sha256_groups.entry(h.to_vec()).or_default().push(i);
        }
        if let Some(h) = &f.pixel_hash {
            pixel_groups.entry(h.to_vec()).or_default().push(i);
        }
    }

    // Files in any exact group are excluded from pixel groups
    let in_exact_group: std::collections::HashSet<usize> = sha256_groups.values()
        .filter(|v| v.len() > 1)
        .flat_map(|v| v.iter().copied())
        .collect();

    let mut groups = Vec::new();
    let mut group_id = 0;

    for (_, members) in sha256_groups.iter().filter(|(_, v)| v.len() > 1) {
        let keeper = pick_keeper(files, members);
        groups.push(DuplicateGroup { group_id, match_type: MatchType::Exact, keeper, files: members.clone() });
        group_id += 1;
    }

    for (_, members) in pixel_groups.iter().filter(|(_, v)| v.len() > 1) {
        // Exclude files already in an exact group
        let filtered: Vec<usize> = members.iter().copied()
            .filter(|i| !in_exact_group.contains(i))
            .collect();
        if filtered.len() > 1 {
            let keeper = pick_keeper(files, &filtered);
            groups.push(DuplicateGroup { group_id, match_type: MatchType::PixelIdentical, keeper, files: filtered });
            group_id += 1;
        }
    }
    groups
}
```

**Step 2 — Write a test for the overlap scenario:**
File: `crates/core/tests/grouper_overlap.rs`
```rust
use dedupe_core::grouper::{build_groups, MatchType};
use dedupe_core::scanner::ScannedFile;

fn make_file(path: &str, sha256: Option<[u8; 32]>, pixel_hash: Option<[u8; 32]>) -> ScannedFile {
    ScannedFile {
        path: std::path::PathBuf::from(path),
        size: 1000,
        mtime_ns: 0,
        sha256,
        pixel_hash,
        error: None,
    }
}

#[test]
fn exact_subsumes_pixel() {
    // A and B are exact duplicates (same SHA-256)
    // B and C share pixel_hash (different SHA-256)
    // B should appear in the exact group, NOT in the pixel group
    let sha_ab = [1u8; 32];
    let pixel_bc = [2u8; 32];
    let sha_c = [3u8; 32];

    let files = vec![
        make_file('/a.jpg', Some(sha_ab), Some([10u8; 32])),  // A: exact with B
        make_file('/b.jpg', Some(sha_ab), Some(pixel_bc)),     // B: exact with A, pixel with C
        make_file('/c.jpg', Some(sha_c), Some(pixel_bc)),      // C: pixel with B
    ];

    let groups = build_groups(&files);

    // Should have exactly 1 exact group (A+B) and 0 or 1 pixel groups
    let exact_groups: Vec<_> = groups.iter().filter(|g| g.match_type == MatchType::Exact).collect();
    let pixel_groups: Vec<_> = groups.iter().filter(|g| g.match_type == MatchType::PixelIdentical).collect();

    assert_eq!(exact_groups.len(), 1, 'expected 1 exact group');
    assert!(!exact_groups[0].files.is_empty());

    // B (index 1) must NOT be in any pixel group
    let b_in_pixel = pixel_groups.iter().any(|g| g.files.contains(&1));
    assert!(!b_in_pixel, 'B (in exact group) must not appear in pixel group');
}
```
