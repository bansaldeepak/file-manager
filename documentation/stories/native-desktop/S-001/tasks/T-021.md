# native-desktop/S-001-T21: Quarantine journal state machine: PENDING → COMPLETED/FAILED/ROLLED_BACK

**Status:** done
**Priority:** P0
**Blocked By:** S-001-T9

## What
Implement the full quarantine operation in `crates/app` using the op_journal state machine: write PENDING before moving, update to COMPLETED/FAILED after, and implement startup reconciliation that resolves PENDING entries from previous crashed runs.

## Why
This is the main Stage 4 deliverable. Without it the app can move files but can't recover from a crash between the move and the journal update, leaving the user with missing source files and no record of where they went.

## Context
State machine (from TRD and CEO review Section 1 diagram):
```
PENDING → COMPLETED (rename succeeded)
        → FAILED    (rename errored)
        → (crash)   → ROLLED_BACK or COMPLETED (startup reconciliation)
```

Startup reconciliation logic (TRD):
- PENDING + source exists + dest missing → ROLLED_BACK (move never happened)
- PENDING + source missing + dest exists → COMPLETED (move happened but journal not updated)
- PENDING + both exist → verify dest hash; if match: COMPLETED + remove source; if no match: alert user

The pre-verify-all-before-moving-any rule (TRD): verify ALL source files before moving ANY. This prevents partial batches.

op_journal schema (defined in T-004):
```sql
operation TEXT CHECK IN ('quarantine', 'restore', 'delete')
status TEXT CHECK IN ('PENDING', 'COMPLETED', 'FAILED', 'ROLLED_BACK')
source_path, dest_path, sha256, keeper_path, cross_volume, created_at, completed_at
```

This task implements both the Tauri commands AND the journal ops in crate:index.

## How

**Step 1 — Create op_journal module in crate:index:**
File: `crates/index/src/op_journal.rs`
```rust
use rusqlite::Connection;
use crate::error::{IndexError, promote};

#[derive(Debug, Clone, PartialEq)]
pub enum OpStatus { Pending, Completed, Failed, RolledBack }

impl OpStatus {
    pub fn as_str(&self) -> &'static str {
        match self {
            Self::Pending => 'PENDING',
            Self::Completed => 'COMPLETED',
            Self::Failed => 'FAILED',
            Self::RolledBack => 'ROLLED_BACK',
        }
    }
}

pub struct JournalEntry {
    pub id: i64,
    pub source_path: String,
    pub dest_path: Option<String>,
    pub sha256: Vec<u8>,
    pub status: String,
    pub cross_volume: bool,
}

pub fn write_pending(conn: &Connection, source: &str, dest: &str, sha256: &[u8], keeper: &str, cross_volume: bool) -> Result<i64, IndexError> {
    conn.execute(
        'INSERT INTO op_journal (operation, status, source_path, dest_path, sha256, keeper_path, cross_volume)
         VALUES ("quarantine", "PENDING", ?1, ?2, ?3, ?4, ?5)',
        rusqlite::params![source, dest, sha256, keeper, cross_volume as i64],
    ).map_err(promote)?;
    Ok(conn.last_insert_rowid())
}

pub fn mark_completed(conn: &Connection, id: i64) -> Result<(), IndexError> {
    conn.execute(
        'UPDATE op_journal SET status="COMPLETED", completed_at=datetime("now") WHERE id=?1',
        [id],
    ).map_err(promote)?;
    Ok(())
}

pub fn mark_failed(conn: &Connection, id: i64, reason: &str) -> Result<(), IndexError> {
    conn.execute(
        'UPDATE op_journal SET status="FAILED", completed_at=datetime("now") WHERE id=?1',
        [id],
    ).map_err(promote)?;
    Ok(())
}

pub fn get_pending(conn: &Connection) -> Result<Vec<JournalEntry>, IndexError> {
    let mut stmt = conn.prepare(
        'SELECT id, source_path, dest_path, sha256, status, cross_volume FROM op_journal WHERE status="PENDING"',
    ).map_err(promote)?;
    let rows = stmt.query_map([], |row| Ok(JournalEntry {
        id: row.get(0)?,
        source_path: row.get(1)?,
        dest_path: row.get(2)?,
        sha256: row.get(3)?,
        status: row.get(4)?,
        cross_volume: row.get::<_, i64>(5)? != 0,
    })).map_err(promote)?;
    rows.collect::<Result<Vec<_>, _>>().map_err(IndexError::Sqlite)
}
```

**Step 2 — Implement startup reconciliation:**
File: `crates/app/src/reconcile.rs`
```rust
use dedupe_index::{op_journal, IndexError};
use dedupe_core::hash::sha256_file;
use rusqlite::Connection;
use tracing::{info, warn};

pub fn reconcile_pending(conn: &Connection) -> Result<Vec<String>, IndexError> {
    let pending = op_journal::get_pending(conn)?;
    let mut alerts = Vec::new();

    for entry in pending {
        let src_exists = std::path::Path::new(&entry.source_path).exists();
        let dst_exists = entry.dest_path.as_ref().map(|d| std::path::Path::new(d).exists()).unwrap_or(false);

        match (src_exists, dst_exists) {
            (true, false) => {
                // Move never happened
                op_journal::mark_rolled_back(conn, entry.id)?;
                info!('Reconciled: {} → ROLLED_BACK (source preserved)', entry.source_path);
            },
            (false, true) => {
                // Move completed but journal not updated
                op_journal::mark_completed(conn, entry.id)?;
                info!('Reconciled: {} → COMPLETED', entry.source_path);
            },
            (true, true) => {
                // Both exist — verify dest
                if let Some(dest) = &entry.dest_path {
                    let dest_hash = sha256_file(std::path::Path::new(dest)).ok();
                    if dest_hash.as_deref() == Some(&entry.sha256) {
                        // Dest is verified — remove source, mark completed
                        std::fs::remove_file(&entry.source_path).ok();
                        op_journal::mark_completed(conn, entry.id)?;
                    } else {
                        // Dest hash mismatch — alert user
                        alerts.push(format!(
                            'Unresolved: {} — both source and destination exist but hashes differ. Manual review required.',
                            entry.source_path
                        ));
                    }
                }
            },
            (false, false) => {
                // Both missing — mark failed
                op_journal::mark_failed(conn, entry.id, 'both source and dest missing')?;
            }
        }
    }
    Ok(alerts)
}
```

**Step 3 — Create quarantine Tauri command:**
File: `crates/app/src/commands/quarantine.rs`
```rust
use std::sync::Mutex;
use dedupe_core::{quarantine as q, hash};
use dedupe_index::{op_journal, file_cache};
use tauri::State;

#[tauri::command]
pub async fn quarantine_files(
    files: Vec<QuarantineRequest>,
    db: State<'_, Mutex<rusqlite::Connection>>,
) -> Result<Vec<String>, String> {
    let conn = db.lock().unwrap();

    // Pre-verify ALL before moving ANY
    for req in &files {
        let actual_hash = hash::sha256_file(std::path::Path::new(&req.source_path))
            .map_err(|e| format!('verify failed for {}: {e}', req.source_path))?;
        if actual_hash.as_slice() != req.expected_sha256.as_slice() {
            return Err(format!('file changed: {} — refresh and retry', req.source_path));
        }
    }

    let mut results = Vec::new();
    for req in &files {
        let dest = compute_quarantine_dest(&req.source_path);
        let dest = q::collision_safe(&dest);
        let journal_id = op_journal::write_pending(&conn, &req.source_path, dest.to_str().unwrap(), &req.expected_sha256, &req.keeper_path, false)
            .map_err(|e| e.to_string())?;
        match q::move_file(std::path::Path::new(&req.source_path), &dest, &req.expected_sha256) {
            Ok(r) => {
                op_journal::mark_completed(&conn, journal_id).ok();
                results.push(dest.to_string_lossy().to_string());
            },
            Err(e) => {
                op_journal::mark_failed(&conn, journal_id, &e.to_string()).ok();
                return Err(format!('move failed for {}: {e}', req.source_path));
            }
        }
    }
    Ok(results)
}

#[derive(serde::Deserialize)]
pub struct QuarantineRequest {
    pub source_path: String,
    pub expected_sha256: Vec<u8>,
    pub keeper_path: String,
}

fn compute_quarantine_dest(source: &str) -> std::path::PathBuf {
    let src = std::path::Path::new(source);
    let name = src.file_name().unwrap_or_default();
    dirs::data_local_dir()
        .unwrap_or_else(|| std::path::PathBuf::from('.'))
        .join('Arcitae/Quarantine')
        .join(name)
}
```
