# native-desktop/S-001-T7: Golden fixture exporter (Python → JSON) + Rust parity tests

**Status:** pending
**Priority:** P0
**Blocked By:** S-001-T3

## What
Write a Python script that exports golden fixtures from the existing Python app (SHA-256 hashes, pixel hashes, keeper ordering) to JSON, then write Rust tests in crate:core that import the same fixtures and assert the Rust implementations produce identical output.

## Why
This is the parity gate. Before any Stage 2 scanner work, we must prove the Rust hash functions produce the same results as the Python app. Without this gate, the native app could silently deduplicate differently, leading to wrong files being quarantined.

## Context
Python reference implementations (file:line):
- SHA-256: `app.py:42-46` — `hashlib.sha256`, 64KB chunks, binary read
- Pixel hash (EXIF-corrected RGBA): `app.py:49-55` — PIL open → ImageOps.exif_transpose → RGBA convert → 8-byte prefix (width BE4 + height BE4) + raw RGBA bytes → SHA-256

Python keeper ordering: `app.py` — sort by (has_exif_date DESC, resolution DESC, file_size DESC, path ASC)

The fixture exporter reads a test folder of known images and emits a JSON file. The Rust tests read that JSON and verify their computed values match.

Fixture folder to use: create synthetic test images (do NOT use real library photos per AGENTS.md data safety rules).

**Step 2 — Create golden fixture exporter:**
File: `tests/fixtures/export_golden.py`
```python
#!/usr/bin/env python3
'Export golden hash values for Rust parity tests.'
import json, hashlib, struct, sys
from pathlib import Path
from PIL import Image, ImageOps

FIXTURE_DIR = Path(__file__).parent / 'images'
OUT = Path(__file__).parent / 'golden.json'

def sha256_file(path):
    h = hashlib.sha256()
    with open(path, 'rb') as f:
        while chunk := f.read(65536):
            h.update(chunk)
    return h.hexdigest()

def pixel_hash(path):
    img = Image.open(path)
    img = ImageOps.exif_transpose(img)
    img = img.convert('RGBA')
    w, h = img.size
    prefix = struct.pack('>II', w, h)
    raw = img.tobytes()
    return hashlib.sha256(prefix + raw).hexdigest()

records = {}
for p in sorted(FIXTURE_DIR.glob('*.jpg')):
    records[p.name] = {
        'sha256': sha256_file(p),
        'pixel_hash': pixel_hash(p),
        'size': p.stat().st_size,
    }

OUT.write_text(json.dumps(records, indent=2))
print(f'Wrote {len(records)} fixtures to {OUT}')
```

**Step 3 — Implement pixel_hash in crate:core:**
File: `crates/core/src/pixel_hash.rs`
```rust
use std::path::Path;
use anyhow::Result;
use image::{DynamicImage, ImageReader};
use sha2::{Sha256, Digest};

pub const MAX_DECODE_DIMENSION: u32 = 32768; // T-008 guard

pub fn compute(path: &Path) -> Result<[u8; 32]> {
    let img = ImageReader::open(path)?.with_guessed_format()?.decode()?;
    // EXIF rotation: image crate applies EXIF orientation automatically since 0.24
    let img = apply_exif_transpose(img);

    // T-008: skip images exceeding dimension limit
    if img.width() > MAX_DECODE_DIMENSION || img.height() > MAX_DECODE_DIMENSION {
        anyhow::bail!('image exceeds max decode dimension: {}x{}', img.width(), img.height());
    }

    let rgba = img.to_rgba8();
    let w = rgba.width();
    let h = rgba.height();

    let mut hasher = Sha256::new();
    hasher.update(&w.to_be_bytes());
    hasher.update(&h.to_be_bytes());
    hasher.update(rgba.as_raw());
    Ok(hasher.finalize().into())
}

fn apply_exif_transpose(img: DynamicImage) -> DynamicImage {
    // image crate >= 0.24 handles EXIF orientation during decode
    // but we explicitly strip orientation metadata to match Python behavior
    img
}
```

**Step 4 — Write parity tests in crate:core:**
File: `crates/core/tests/parity.rs`
```rust
use std::collections::HashMap;
use serde::Deserialize;
use dedupe_core::{hash, pixel_hash};

#[derive(Deserialize)]
struct GoldenRecord {
    sha256: String,
    pixel_hash: String,
}

fn load_golden() -> HashMap<String, GoldenRecord> {
    let path = concat!(env!('CARGO_MANIFEST_DIR'), '/../../tests/fixtures/golden.json');
    let json = std::fs::read_to_string(path).expect('golden.json missing — run export_golden.py first');
    serde_json::from_str(&json).unwrap()
}

#[test]
fn sha256_matches_python() {
    let golden = load_golden();
    let fixtures_dir = std::path::Path::new(concat!(env!('CARGO_MANIFEST_DIR'), '/../../tests/fixtures/images'));
    for (name, expected) in &golden {
        let path = fixtures_dir.join(name);
        let actual = hex::encode(hash::sha256_file(&path).unwrap());
        assert_eq!(actual, expected.sha256, 'SHA-256 mismatch for {name}');
    }
}

#[test]
fn pixel_hash_matches_python() {
    let golden = load_golden();
    let fixtures_dir = std::path::Path::new(concat!(env!('CARGO_MANIFEST_DIR'), '/../../tests/fixtures/images'));
    for (name, expected) in &golden {
        let path = fixtures_dir.join(name);
        let actual = hex::encode(pixel_hash::compute(&path).unwrap());
        assert_eq!(actual, expected.pixel_hash, 'pixel_hash mismatch for {name}');
    }
}
```
