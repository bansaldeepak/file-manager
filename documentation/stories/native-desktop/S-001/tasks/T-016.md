# native-desktop/S-001-T16: Tab bar (Photos / Videos / All) in toolbar — DD3

**Status:** pending
**Priority:** P2
**Blocked By:** S-001-T14

## What
Add a three-tab bar (Photos / Videos / All) in the toolbar, left of center. The active tab filters the contact sheet to show only the selected media type. Uses the DESIGN.md tab style (SF Pro Text 13px medium, vermillion underline for active tab).

## Why
Design decision DD3: 'Tab bar (Photos / Videos / All) per DD3.' The Python app has no media type filter. For large libraries with mixed media, being able to focus on just photos during a dedupe session is a significant usability win.

## Context
DESIGN.md toolbar spec: 'Tabs (Photos / Videos / All) per DD3.'
Tab styling per DESIGN.md general conventions:
- Font: var(--font-body) 13px, medium weight for active state
- Active indicator: 2px vermillion underline (not background highlight)
- Inactive: regular weight, text-muted color

Tab values: 'photos' | 'videos' | 'all'. Default: 'photos'.

File type buckets (for filtering):
- Photos: .jpg, .jpeg, .png, .heic, .heif, .webp, .tiff, .tif, .bmp, .raw, .cr2, .nef, .arw, .dng
- Videos: .mp4, .mov, .m4v, .avi, .mkv, .mts, .m2ts (note: video dedup is deferred to post-MVP; this tab just shows 0 results for now)
- All: everything

## How

**Step 1 — Create TabBar component:**
File: `src/components/TabBar.tsx`
```tsx
import React from 'react';
import './TabBar.css';

export type MediaTab = 'photos' | 'videos' | 'all';

interface TabBarProps {
  value: MediaTab;
  onChange: (tab: MediaTab) => void;
}

const TABS: { value: MediaTab; label: string }[] = [
  { value: 'photos', label: 'Photos' },
  { value: 'videos', label: 'Videos' },
  { value: 'all', label: 'All' },
];

export function TabBar({ value, onChange }: TabBarProps) {
  return (
    <div className='tab-bar' role='tablist' aria-label='Media type filter'>
      {TABS.map(tab => (
        <button
          key={tab.value}
          role='tab'
          aria-selected={value === tab.value}
          className='tab-button'
          data-active={value === tab.value}
          onClick={() => onChange(tab.value)}
        >
          {tab.label}
        </button>
      ))}
    </div>
  );
}
```
