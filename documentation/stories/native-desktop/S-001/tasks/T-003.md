# native-desktop/S-001-T3: Initialize Rust workspace: core + index + app crates

**Status:** done
**Priority:** P0
**Blocked By:** —

## What
Create a Cargo workspace with three crates (core, index, app) in the project root alongside the existing Python app. Initialize Cargo.toml workspace file, create each crate with cargo init, add a .gitignore covering Rust artifacts, and add baseline dependencies.

## Why
This is the foundation for all Stage 1+ work. No Rust implementation tasks can proceed until the workspace exists. D2 (CEO review) approved 2-3 crates starting simple; this creates the minimal structure that Stage 2 scanner and Stage 4 quarantine code will live in.

## Context
CEO review D2: Start with 2-3 crates (core + index + app), split when working code reveals real seams. Do NOT create 6 crates upfront.

Crate responsibilities (from TRD):
- `crate:core` — scanner, sha256, pixel_hash, grouper, keeper_logic, quarantine, restore, collision
- `crate:index` — SQLite schema, migrations, file_cache queries, op_journal queries
- `crate:app` — thin Tauri 2 command layer, event emitters; delegates all logic to core + index

D7: Git init this project before Stage 1 starts. The workspace creation IS the Stage 1 git init.

The Python app (app.py, folder_review.py, etc.) must remain untouched. The Rust workspace lives alongside it, not replacing it.

## How

**Step 1 — Git init (D7):**
```bash
cd /Users/db/Work/Arcitae/image-dedupe
git init
git add app.py folder_review.py requirements.txt README.md REQUIREMENTS.md DESIGN.md AGENTS.md CLAUDE.md documentation/
git commit -m 'chore: preserve Python app before Rust workspace init'
```

**Step 2 — Create Cargo workspace Cargo.toml at project root:**
File: `Cargo.toml`
```toml
[workspace]
members = [
    'crates/core',
    'crates/index',
    'crates/app',
]
resolver = '2'

[workspace.dependencies]
anyhow = '1'
thiserror = '1'
serde = { version = '1', features = ['derive'] }
serde_json = '1'
tokio = { version = '1', features = ['full'] }
tracing = '0.1'
tracing-subscriber = { version = '0.3', features = ['env-filter'] }
```

**Step 3 — Create each crate:**
```bash
mkdir -p crates
cargo init --lib crates/core --name dedupe-core
cargo init --lib crates/index --name dedupe-index
cargo init --lib crates/app --name dedupe-app
```

**Step 4 — Add cross-crate dependencies in each Cargo.toml:**
File: `crates/index/Cargo.toml` — add:
```toml
[dependencies]
dedupe-core = { path = '../core' }
rusqlite = { version = '0.31', features = ['bundled'] }
anyhow.workspace = true
thiserror.workspace = true
serde.workspace = true
```

File: `crates/app/Cargo.toml` — add:
```toml
[dependencies]
dedupe-core = { path = '../core' }
dedupe-index = { path = '../index' }
tauri = { version = '2', features = [] }
anyhow.workspace = true
serde.workspace = true
serde_json.workspace = true
tokio.workspace = true
tracing.workspace = true
tracing-subscriber.workspace = true
```

**Step 5 — Add .gitignore entries for Rust:**
File: `.gitignore`
Append:
```
/target/
Cargo.lock
*.swp
dedupe_cache.sqlite3
dedupe_cache.sqlite3-shm
dedupe_cache.sqlite3-wal
review_decisions.json
.DS_Store
```

**Step 6 — Verify workspace builds:**
```bash
cargo build --workspace 2>&1 | tail -20
cargo test --workspace 2>&1 | tail -20
```
