# native-desktop/S-001-T28: Scripted smoke test for packaged .app

**Status:** done
**Priority:** P3
**Blocked By:** S-001-T26

## What
Write a scripted smoke test that verifies the packaged Arcitae Dedupe .app works end-to-end on a clean macOS account: launch the app, confirm the window opens, scan the test fixture folder, verify the expected duplicate groups appear, quit cleanly. This runs as part of the pre-release check script from T-026.

## Why
CEO review Section 9 WARNING: 'No automated smoke test for packaged .app specified.' Tauri dev mode and a packaged .app can behave differently (sandboxing, code signing, entitlements, path resolution). The smoke test catches regressions that only appear in the packaged build.

## Context
The smoke test operates on the packaged DMG/app, not the dev build. It uses the test fixture images from T-007 (tests/fixtures/images/).

Testing approach: AppleScript can launch an app and check if a window is open. For deeper functional testing (scan result verification), the app can optionally accept a `--smoke-test` CLI argument that runs a headless scan and exits with a result code.

Alternative simpler approach: write a Tauri CLI command `arcitae-dedupe --smoke-test /path/to/fixtures` that scans and exits 0 if at least 1 duplicate group found, 1 otherwise. The smoke test script calls this.

## How

**Step 1 — Add smoke-test CLI mode to the Tauri app:**
File: `crates/app/src/main.rs` (update)
```rust
fn main() {
    let args: Vec<String> = std::env::args().collect();

    if args.get(1).map(|s| s.as_str()) == Some('--smoke-test') {
        let fixture_dir = args.get(2).map(|s| std::path::PathBuf::from(s))
            .unwrap_or_else(|| std::path::PathBuf::from('tests/fixtures/images'));
        std::process::exit(run_smoke_test(&fixture_dir));
    }

    // ... normal Tauri startup
}

fn run_smoke_test(fixture_dir: &std::path::Path) -> i32 {
    use dedupe_core::{scanner, grouper};

    eprintln!('Smoke test: scanning {}', fixture_dir.display());

    let files = match scanner::scan_directory(fixture_dir, None, |_| {}) {
        Ok(f) => f,
        Err(e) => { eprintln!('Scan failed: {e}'); return 1; }
    };

    if files.is_empty() {
        eprintln!('Smoke test FAIL: no files found in {}', fixture_dir.display());
        return 1;
    }

    let groups = grouper::build_groups(&files);
    let exact_count = groups.iter().filter(|g| g.match_type == dedupe_core::grouper::MatchType::Exact).count();

    if exact_count == 0 {
        eprintln!('Smoke test FAIL: expected at least 1 exact duplicate group, found 0');
        return 1;
    }

    eprintln!('Smoke test PASS: {} files, {} duplicate groups ({} exact)', files.len(), groups.len(), exact_count);
    0
}
```

**Step 2 — Create smoke test script:**
File: `scripts/smoke-test.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail

APP_PATH='${1:-/Applications/Arcitae Dedupe.app}'
FIXTURE_DIR='$(cd $(dirname $0)/..; pwd)/tests/fixtures/images'

echo '=== Smoke Test ==='
echo 'App: '$APP_PATH
echo 'Fixtures: '$FIXTURE_DIR

# Check fixtures exist
if [ ! -d '$FIXTURE_DIR' ]; then
    echo 'FAIL: fixture directory not found. Run: python tests/fixtures/gen_fixtures.py'
    exit 1
fi

# Check app exists
if [ ! -d '$APP_PATH' ]; then
    echo 'FAIL: .app not found at '$APP_PATH
    echo 'Build first: pnpm tauri build'
    exit 1
fi

# Run headless smoke test
'$APP_PATH/Contents/MacOS/arcitae-dedupe' --smoke-test '$FIXTURE_DIR'
STATUS=$?

if [ $STATUS -eq 0 ]; then
    echo '=== Smoke Test PASSED ==='
else
    echo '=== Smoke Test FAILED (exit '$STATUS') ==='
fi
exit $STATUS
```

Make executable:
```bash
chmod +x scripts/smoke-test.sh
```
