# native-desktop/S-001-T20: Responsive layout breakpoints (3-pane / 2-pane / 1-pane)

**Status:** done
**Priority:** P3
**Blocked By:** S-001-T14

## What
Verify and harden the responsive layout breakpoints in AppShell: >= 1200px shows all three panes, 900-1199px collapses the sidebar to a drawer accessible via a toolbar button, under 900px shows single pane with a back navigation. Add the sidebar drawer mechanism for the 900-1199px case.

## Why
DESIGN.md layout spec: 'At >= 1200px all three panes. 900-1199px: sidebar collapses to toolbar-accessible drawer. <900px: single pane with back control.' T-014 laid the CSS breakpoints but did not implement the drawer mechanism. Without this, the app is unusable on smaller displays (laptops, external monitors at non-standard sizes).

## Context
The CSS breakpoints in AppShell.css (T-014) hide the sidebar at < 1200px but there's no way to access it. This task adds:
1. A sidebar toggle button in the toolbar (icon-only, appears at 900-1199px)
2. A slide-in sidebar drawer at 900-1199px (200ms ease-out, matching DESIGN.md motion spec)
3. At < 900px, the inspector is also hidden; back button navigates between panes

DESIGN.md motion spec: 'enter(ease-out) exit(ease-in); short(150-250ms)'

## How

**Step 1 — Add sidebar toggle state and drawer:**
File: `src/components/AppShell.tsx` (update)
```tsx
const [sidebarOpen, setSidebarOpen] = useState(false);

// In render, update sidebar:
<nav 
  className='sidebar'
  data-drawer-open={sidebarOpen}
  aria-label='Folder navigation'
>
  {sidebar}
</nav>

// In toolbar, add toggle button (conditionally rendered):
<button
  className='sidebar-toggle'
  onClick={() => setSidebarOpen(o => !o)}
  aria-label={sidebarOpen ? 'Close sidebar' : 'Open sidebar'}
  aria-expanded={sidebarOpen}
>
  ☰
</button>
```

**Step 2 — Update CSS for drawer behavior:**
File: `src/components/AppShell.css` (update)
```css
/* Sidebar drawer at 900-1199px */
@media (max-width: 1199px) {
  .sidebar {
    position: fixed;
    top: var(--toolbar-height);
    left: 0;
    height: calc(100vh - var(--toolbar-height));
    z-index: 100;
    background: var(--color-surface);
    border-right: 1px solid color-mix(in srgb, var(--color-text) 10%, transparent);
    transform: translateX(-100%);
    transition: transform 200ms ease-out;
    box-shadow: 0 8px 32px rgba(0,0,0,0.12);
  }

  .sidebar[data-drawer-open='true'] {
    transform: translateX(0);
  }

  .sidebar-toggle {
    display: flex;
    align-items: center;
    justify-content: center;
    width: 32px;
    height: 32px;
    background: none;
    border: none;
    border-radius: var(--radius-sm);
    color: var(--color-text);
    cursor: pointer;
    font-size: 16px;
  }
}

@media (min-width: 1200px) {
  .sidebar-toggle { display: none; }
}

/* Single pane at <900px: hide inspector */
@media (max-width: 899px) {
  .inspector { display: none; }
}
```

**Step 3 — Close sidebar on outside click:**
```tsx
// In AppShell, add effect:
useEffect(() => {
  if (!sidebarOpen) return;
  const close = (e: MouseEvent) => {
    const sidebar = document.querySelector('.sidebar');
    if (sidebar && !sidebar.contains(e.target as Node)) setSidebarOpen(false);
  };
  document.addEventListener('mousedown', close);
  return () => document.removeEventListener('mousedown', close);
}, [sidebarOpen]);
```

**Step 4 — Verify:**
```bash
pnpm dev
# Verify by resizing browser window:
# - At 1200px+: all three panes visible, no toggle button
# - At 900-1199px: sidebar hidden, toggle button appears in toolbar
# - Click toggle: sidebar slides in from left in ~200ms
# - Click outside sidebar: sidebar slides back
# - At <900px: only contact sheet visible
```
