# native-desktop/S-001-T19: Thumbnail zoom slider (100–300px) in footer — DD8

**Status:** pending
**Priority:** P2
**Blocked By:** S-001-T14

## What
Add a thumbnail zoom slider in the app footer (below the contact sheet), ranging from 100px to 300px in 32px increments per DESIGN.md. The slider value controls the width of thumbnails in the contact sheet grid. Default is 160px.

## Why
Design decision DD8: 'Thumbnail zoom 100–300px in 32px footer.' Photo reviewers vary in how many thumbnails they want to see at once. A large library reviewer wants small thumbnails (more groups visible); a reviewer focused on detail comparison wants large ones. Fixed sizing is a major usability miss.

## Context
DESIGN.md footer spec: 'Thumbnail default 160px per DD8. Zoom slider 100–300px in 32px footer.'
The 32px in 'DD8' refers to the footer height being 32px (not the step). Step increment can be continuous (range input) — the 32px is the footer bar height.

The slider is a standard HTML range input styled to match the design system. The thumbnail size value is a shared state lifted to App.tsx and passed to the contact sheet grid.

## How

**Step 1 — Create ZoomSlider component:**
File: `src/components/ZoomSlider.tsx`
```tsx
import React from 'react';
import './ZoomSlider.css';

interface ZoomSliderProps {
  value: number;       // current thumbnail size in px (100-300)
  onChange: (size: number) => void;
}

export function ZoomSlider({ value, onChange }: ZoomSliderProps) {
  return (
    <div className='zoom-slider' aria-label='Thumbnail size'>
      <span className='zoom-icon zoom-small' aria-hidden>⊞</span>
      <input
        type='range'
        min={100}
        max={300}
        step={10}
        value={value}
        onChange={e => onChange(Number(e.target.value))}
        className='zoom-range'
        aria-label={}
        aria-valuemin={100}
        aria-valuemax={300}
        aria-valuenow={value}
        aria-valuetext={}
      />
      <span className='zoom-icon zoom-large' aria-hidden>⊞</span>
    </div>
  );
}
```

File: `src/components/ZoomSlider.css`
```css
.zoom-slider {
  display: flex;
  align-items: center;
  gap: var(--spacing-sm);
  height: 100%;
}

.zoom-icon {
  color: var(--color-text-muted);
  font-size: 12px;
  user-select: none;
}

.zoom-small { font-size: 10px; }
.zoom-large { font-size: 14px; }

.zoom-range {
  width: 100px;
  accent-color: var(--color-primary);
  cursor: pointer;
}
```

**Step 2 — Create app footer and add it to AppShell:**
File: `src/components/AppShell.tsx` (update)

Add `footer` to AppShellProps interface:
```tsx

```

Add footer bar below panes in render:
```tsx

```

Add to AppShell.css:
```css

```

**Step 3 — Wire up in App.tsx:**
```tsx

<AppShell

  // ...

```
