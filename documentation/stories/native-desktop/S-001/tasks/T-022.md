# native-desktop/S-001-T22: Post-quarantine summary banner with Undo — DD5

**Status:** pending
**Priority:** P2
**Blocked By:** S-001-T21

## What
Show a post-quarantine summary banner at the top of the contact sheet after a successful quarantine operation: 'Moved N files (X MB). Undo' with a 5-second auto-dismiss and a permanent Undo option in the quarantine history view. Banner slides in from top in 300ms ease-out per DESIGN.md.

## Why
Design decision DD5: 'Post-quarantine summary banner with Undo.' DESIGN.md: 'Banner per DD5: Post-quarantine summary with byte count and Undo. 300ms ease-out from top. Auto-dismiss 5s. Undo always available in Quarantine view after.' Without this, the user has no feedback that the quarantine succeeded, and no easy way to recover a mistake.

## Context
DESIGN.md component spec:
- 'Banner per DD5: Post-quarantine summary with byte count and Undo. 300ms ease-out from top. Auto-dismiss 5s.'
- 'Undo always available in Quarantine view after.'
- Motion: 'The one authored moment: Post-quarantine banner (DD5) — 300ms ease-out from top, auto-dismiss 5s.'

DESIGN.md destructive color note: Undo is a recovery action, not destructive. Use var(--color-primary) (vermillion) for the Undo button text, NOT var(--color-destructive).

Keyboard shortcut Cmd+Z (T-018) should also trigger Undo. For this task, just connect Cmd+Z to the Undo action when the banner is visible.

## How

**Step 1 — Create BannerStack component:**
File: `src/components/Banner.tsx`
```tsx
import React, { useEffect, useState } from 'react';
import './Banner.css';

interface BannerProps {
  message: string;
  onUndo?: () => void;
  onDismiss: () => void;
  autoDismissMs?: number;
}

export function Banner({ message, onUndo, onDismiss, autoDismissMs = 5000 }: BannerProps) {
  const [visible, setVisible] = useState(false);

  useEffect(() => {
    // Trigger enter animation on mount
    requestAnimationFrame(() => setVisible(true));

    const timer = setTimeout(() => {
      setVisible(false);
      setTimeout(onDismiss, 300); // wait for exit animation
    }, autoDismissMs);

    return () => clearTimeout(timer);
  }, [autoDismissMs, onDismiss]);

  return (
    <div className='banner' data-visible={visible} role='status' aria-live='polite'>
      <span className='banner-message'>{message}</span>
      {onUndo && (
        <button className='banner-undo' onClick={onUndo}>
          Undo
        </button>
      )}
      <button className='banner-close' onClick={() => { setVisible(false); setTimeout(onDismiss, 300); }} aria-label='Dismiss'>
        ×
      </button>
    </div>
  );
}
```
