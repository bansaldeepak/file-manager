# native-desktop/S-001-T4: SQLite schema with WAL mode and migrations in crate:index

**Status:** pending
**Priority:** P1
**Blocked By:** S-001-T3

## What
Implement the SQLite database schema in `crates/index` with WAL journal mode, all three tables (file_cache, op_journal, scan_metadata), a versioned migration runner, and typed Rust query wrappers for the scanner's read/write path.

## Why
Every Stage 2+ feature (scanner, grouper, quarantine) depends on the index. The schema must be in place with correct WAL mode before parallel scan workers can safely read and write. E9 (eng review) identified WAL mode as required; without it concurrent readers block on writers.

## Context
TRD schema (canonical, copy these exactly):
```sql
CREATE TABLE file_cache (
    id INTEGER PRIMARY KEY,
    path TEXT NOT NULL UNIQUE,
    size INTEGER NOT NULL,
    mtime_ns INTEGER NOT NULL,
    analyzer_version INTEGER NOT NULL DEFAULT 1,
    sha256 BLOB,
    pixel_hash BLOB,
    error TEXT,
    scanned_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE op_journal (
    id INTEGER PRIMARY KEY,
    operation TEXT NOT NULL CHECK(operation IN ('quarantine', 'restore', 'delete')),
    status TEXT NOT NULL CHECK(status IN ('PENDING', 'COMPLETED', 'FAILED', 'ROLLED_BACK')),
    source_path TEXT NOT NULL,
    dest_path TEXT,
    sha256 BLOB NOT NULL,
    keeper_path TEXT,
    cross_volume INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    completed_at TEXT
);

CREATE TABLE scan_metadata (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

PRAGMA journal_mode=WAL;
```

Migration runner design:
- Schema version stored in scan_metadata: key='schema_version', value='1'
- Each migration is a function: fn migrate_to_v1(conn: &Connection) -> Result<()>
- Runner checks current version, applies migrations in order
- Migration failure must propagate to Tauri startup (Task T-010 handles the dialog)

E9 (eng review T21): WAL mode must be set on every connection open, not just at schema creation.

```rust
use thiserror::Error;

#[derive(Debug, Error)]
pub enum IndexError {
    #[error('SQLite error: {0}')]
    Sqlite(#[from] rusqlite::Error),
    #[error('Migration failed at version {version}: {source}')]
    Migration { version: u32, source: rusqlite::Error },
    #[error('Database full — free disk space and retry')]
    DiskFull,
    #[error('IO error: {0}')]
    Io(#[from] std::io::Error),
}
```

**Step 3 — Create migration runner:**
File: `crates/index/src/migrations.rs`
```rust
use rusqlite::Connection;
use crate::error::IndexError;

const CURRENT_VERSION: u32 = 1;

pub fn run(conn: &Connection) -> Result<(), IndexError> {
    let version = get_version(conn).unwrap_or(0);
    if version < 1 { migrate_to_v1(conn)?; }
    Ok(())
}

fn get_version(conn: &Connection) -> Option<u32> {
    conn.query_row(
        'SELECT value FROM scan_metadata WHERE key = ?1',
        ['schema_version'],
        |row| row.get::<_, String>(0),
    ).ok()?.parse().ok()
}

fn migrate_to_v1(conn: &Connection) -> Result<(), IndexError> {
    conn.execute_batch('
        CREATE TABLE IF NOT EXISTS file_cache (
            id INTEGER PRIMARY KEY,
            path TEXT NOT NULL UNIQUE,
            size INTEGER NOT NULL,
            mtime_ns INTEGER NOT NULL,
            analyzer_version INTEGER NOT NULL DEFAULT 1,
            sha256 BLOB,
            pixel_hash BLOB,
            error TEXT,
            scanned_at TEXT NOT NULL DEFAULT (datetime("now"))
        );
        CREATE TABLE IF NOT EXISTS op_journal (
            id INTEGER PRIMARY KEY,
            operation TEXT NOT NULL CHECK(operation IN ("quarantine", "restore", "delete")),
            status TEXT NOT NULL CHECK(operation IN ("PENDING", "COMPLETED", "FAILED", "ROLLED_BACK")),
            source_path TEXT NOT NULL,
            dest_path TEXT,
            sha256 BLOB NOT NULL,
            keeper_path TEXT,
            cross_volume INTEGER NOT NULL DEFAULT 0,
            created_at TEXT NOT NULL DEFAULT (datetime("now")),
            completed_at TEXT
        );
        CREATE TABLE IF NOT EXISTS scan_metadata (
            key TEXT PRIMARY KEY,
            value TEXT NOT NULL,
            updated_at TEXT NOT NULL DEFAULT (datetime("now"))
        );
        INSERT OR REPLACE INTO scan_metadata (key, value) VALUES ("schema_version", "1");
    ').map_err(|e| IndexError::Migration { version: 1, source: e })
}
```

**Step 4 — Create DB open function with WAL:**
File: `crates/index/src/db.rs`
```rust
use rusqlite::{Connection, OpenFlags};
use std::path::Path;
use crate::error::IndexError;
use crate::migrations;

pub fn open(path: &Path) -> Result<Connection, IndexError> {
    let conn = Connection::open_with_flags(path, OpenFlags::SQLITE_OPEN_READ_WRITE | OpenFlags::SQLITE_OPEN_CREATE)?;
    // WAL must be set on every connection open (E9)
    conn.execute_batch('PRAGMA journal_mode=WAL; PRAGMA foreign_keys=ON;')?;
    migrations::run(&conn)?;
    Ok(conn)
}
```
