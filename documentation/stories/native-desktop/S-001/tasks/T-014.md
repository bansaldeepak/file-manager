# native-desktop/S-001-T14: Tauri 2 init + React scaffold: three-pane layout per DESIGN.md

**Status:** done
**Priority:** P0
**Blocked By:** S-001-T3

## What
Initialize the Tauri 2 project inside `crates/app`, set up the React + TypeScript frontend with Vite, and implement the three-pane shell layout exactly matching DESIGN.md: 224px folder nav sidebar (left), flex contact sheet (center), 336px inspector (right). This scaffold unblocks all Stage 3 UI tasks.

## Why
This is the Stage 3 foundation. Every UI task (T-015 through T-020) depends on this scaffold existing. Without it there is no app window to build into.

## Context
DESIGN.md layout spec (read DESIGN.md in full before starting this task):
- Three-pane desktop: sidebar 224px / contact sheet flex / inspector 336px
- At >= 1200px: all three panes visible
- 900-1199px: sidebar collapses to toolbar-accessible drawer
- <900px: single pane with back control
- Toolbar: 52px height
- 8px base grid; outer margins 20px; thumbnail gap 12px
- Colors (light mode): surface #FFFFFF, text #1A1C20, muted #6B707A, primary #C83C2C
- Typography: SF Pro family (system fonts via -apple-system)
- Components: nav-link text #1A1C20, button-primary bg #C83C2C

Tauri 2 init creates its own `src-tauri/` directory. For this project, `src-tauri/` maps to `crates/app/`. If `tauri init` wants to create `src-tauri/`, configure it to output into `crates/app/`.

D4 (CEO review): Drag-and-drop folder selection alongside native picker. The folder selection drop zone lives in the sidebar.

**Step 3 — Create the three-pane shell layout:**
File: `src/components/AppShell.tsx`
```tsx
import React, { useState } from 'react';
import './AppShell.css';

interface AppShellProps {
  sidebar: React.ReactNode;
  contactSheet: React.ReactNode;
  inspector: React.ReactNode;
}

export function AppShell({ sidebar, contactSheet, inspector }: AppShellProps) {
  const [inspectorOpen, setInspectorOpen] = useState(false);

  return (
    <div className='app-shell'>
      <div className='toolbar' />
      <div className='panes'>
        <nav className='sidebar'>{sidebar}</nav>
        <main className='contact-sheet'>{contactSheet}</main>
        <aside className='inspector' data-open={inspectorOpen}>{inspector}</aside>
      </div>
    </div>
  );
}
```
