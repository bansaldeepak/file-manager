# native-desktop/S-001-T9: SQLITE_FULL error handler: surface 'disk full' to user

**Status:** done
**Priority:** P1
**Blocked By:** S-001-T4

## What
Catch the SQLITE_FULL error condition in `crates/index` and convert it to `IndexError::DiskFull` with a clear human-readable message. Add a file_cache write helper that uses this promotion. The Tauri command layer will forward DiskFull as an error toast.

## Why
CEO review CRITICAL GAP #2: 'Disk-full during SQLite write. No rescue specified for SQLITE_FULL.' Without this handler, a disk-full condition causes a generic rusqlite error that the frontend receives as an opaque blob. The user sees nothing meaningful and has no idea what to do.

## Context
rusqlite error representation: disk-full surfaces as `rusqlite::Error::SqliteFailure` with `err.code == rusqlite::ErrorCode::DiskFull` (extended_code 13).

IndexError::DiskFull is already declared in `crates/index/src/error.rs` (T-004):
```rust
#[error('Database full — free disk space and retry')]
DiskFull,
```

All index write paths (file_cache inserts, op_journal inserts) must use a helper that promotes this specific error code.

## How

**Step 1 — Add error promotion helper to error.rs:**
File: `crates/index/src/error.rs` (append)
```rust
pub fn promote(e: rusqlite::Error) -> IndexError {
    match &e {
        rusqlite::Error::SqliteFailure(err, _)
            if err.code == rusqlite::ErrorCode::DiskFull => IndexError::DiskFull,
        _ => IndexError::Sqlite(e),
    }
}
```

**Step 2 — Create file_cache module with promoted write:**
File: `crates/index/src/file_cache.rs`
```rust
use rusqlite::{Connection, OptionalExtension};
use crate::error::{IndexError, promote};

pub struct FileCacheRecord<'a> {
    pub path: &'a str,
    pub size: i64,
    pub mtime_ns: i64,
    pub analyzer_version: i32,
    pub sha256: Option<&'a [u8]>,
    pub pixel_hash: Option<&'a [u8]>,
    pub error: Option<&'a str>,
}

pub fn upsert(conn: &Connection, rec: &FileCacheRecord) -> Result<(), IndexError> {
    conn.execute(
        'INSERT OR REPLACE INTO file_cache
         (path, size, mtime_ns, analyzer_version, sha256, pixel_hash, error, scanned_at)
         VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7, datetime("now"))',
        rusqlite::params![
            rec.path, rec.size, rec.mtime_ns, rec.analyzer_version,
            rec.sha256, rec.pixel_hash, rec.error
        ],
    ).map_err(promote)?;
    Ok(())
}

#[derive(Debug)]
pub struct CachedFile {
    pub id: i64,
    pub path: String,
    pub size: i64,
    pub mtime_ns: i64,
    pub sha256: Option<Vec<u8>>,
    pub pixel_hash: Option<Vec<u8>>,
    pub error: Option<String>,
}

pub fn get_by_path(conn: &Connection, path: &str) -> Result<Option<CachedFile>, IndexError> {
    conn.query_row(
        'SELECT id, path, size, mtime_ns, sha256, pixel_hash, error
         FROM file_cache WHERE path = ?1',
        [path],
        |row| Ok(CachedFile {
            id: row.get(0)?,
            path: row.get(1)?,
            size: row.get(2)?,
            mtime_ns: row.get(3)?,
            sha256: row.get(4)?,
            pixel_hash: row.get(5)?,
            error: row.get(6)?,
        }),
    ).optional().map_err(promote)
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn promote_converts_disk_full() {
        let ffi_err = rusqlite::ffi::Error {
            code: rusqlite::ErrorCode::DiskFull,
            extended_code: 13,
        };
        let sql_err = rusqlite::Error::SqliteFailure(ffi_err, Some('database or disk is full'.to_string()));
        let promoted = promote(sql_err);
        assert!(matches!(promoted, IndexError::DiskFull));
    }

    #[test]
    fn promote_keeps_other_errors() {
        let ffi_err = rusqlite::ffi::Error {
            code: rusqlite::ErrorCode::NotFound,
            extended_code: 0,
        };
        let sql_err = rusqlite::Error::SqliteFailure(ffi_err, None);
        let promoted = promote(sql_err);
        assert!(matches!(promoted, IndexError::Sqlite(_)));
    }
}
```
