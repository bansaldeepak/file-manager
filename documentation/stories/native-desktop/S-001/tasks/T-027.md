# native-desktop/S-001-T27: Log rotation: tracing-appender 10MB size cap

**Status:** done
**Priority:** P3
**Blocked By:** S-001-T3

## What
Set up structured logging in the Tauri app using `tracing` + `tracing-appender` with a 10MB rolling size cap and path filtering to avoid logging personal file paths at INFO level. This prevents the log file from growing unboundedly during long scan sessions.

## Why
CEO review Section 8 WARNING: 'No log rotation specified. tracing with tracing-appender can rotate, but for a desktop app, a single log file with size cap (~10MB) is sufficient.' REQUIREMENTS.md s11: 'Do not log image content or unnecessarily expose personal file paths.' Without size capping, daily scans over weeks fill the disk with log files.

## Context
REQUIREMENTS.md s11 path filtering: file paths should be logged at DEBUG level only, not INFO. Scan progress counters (files_scanned, errors) are fine at INFO.

Log file location: `$LOCALDATA/Arcitae/logs/dedupe.log`
Rotation strategy: single file with 10MB cap (rolling_file or manual truncate). tracing-appender's built-in rolling appender rotates by time, not size. For size-based cap, use the `rolling_file` crate or a custom appender.

Alternatively (simpler): use `tracing-appender` with daily rotation, and document that log files older than 7 days should be deleted (add a startup cleanup step).

## How

**Step 1 — Add tracing dependencies:**
File: `crates/app/Cargo.toml`
```toml
[dependencies]
tracing = { workspace = true }
tracing-subscriber = { workspace = true, features = ['env-filter'] }
tracing-appender = '0.2'
```

**Step 2 — Set up logging with daily rotation and startup cleanup:**
File: `crates/app/src/logging.rs`
```rust
use std::path::Path;
use tracing_appender::rolling::{RollingFileAppender, Rotation};
use tracing_subscriber::{fmt, layer::SubscriberExt, util::SubscriberInitExt, EnvFilter};

pub struct LogGuard {
    _guard: tracing_appender::non_blocking::WorkerGuard,
}

pub fn init(log_dir: &Path) -> LogGuard {
    std::fs::create_dir_all(log_dir).ok();

    // Delete log files older than 7 days
    cleanup_old_logs(log_dir);

    let file_appender = RollingFileAppender::builder()
        .rotation(Rotation::DAILY)
        .filename_prefix('dedupe')
        .filename_suffix('log')
        .max_log_files(7)  // tracing-appender 0.2.9+ supports max_log_files
        .build(log_dir)
        .expect('failed to create log appender');

    let (non_blocking, guard) = tracing_appender::non_blocking(file_appender);

    tracing_subscriber::registry()
        .with(EnvFilter::try_from_default_env()
            .unwrap_or_else(|_| EnvFilter::new('info,dedupe_core=debug')))
        .with(fmt::layer()
            .with_writer(non_blocking)
            .with_ansi(false))
        .init();

    LogGuard { _guard: guard }
}

fn cleanup_old_logs(log_dir: &Path) {
    let cutoff = std::time::SystemTime::now()
        .checked_sub(std::time::Duration::from_secs(7 * 24 * 3600))
        .unwrap_or(std::time::UNIX_EPOCH);

    let Ok(entries) = std::fs::read_dir(log_dir) else { return };
    for entry in entries.flatten() {
        if let Ok(meta) = entry.metadata() {
            if let Ok(modified) = meta.modified() {
                if modified < cutoff {
                    std::fs::remove_file(entry.path()).ok();
                }
            }
        }
    }
}
```

**Step 3 — Call logging::init from main:**
File: `crates/app/src/main.rs` (update)

```rust
fn main() {
    let log_dir = dirs::data_local_dir()
        .unwrap_or_else(|| std::path::PathBuf::from('.'))
        .join('Arcitae/logs');

    let _log_guard = logging::init(&log_dir);
    tracing::info!('Arcitae Dedupe starting');

}
```

**Step 4 — Add path-level logging filter to scanner:**
The scanner (T-011) logs file paths at WARN level (errors) and DEBUG (per-file progress). Verify it does NOT log paths at INFO:
```bash

```
Any INFO-level log containing file paths should be demoted to DEBUG.
