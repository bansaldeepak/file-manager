# native-desktop/S-001-T6: Cross-volume copy-verify-remove in core::quarantine

**Status:** done
**Priority:** P2
**Blocked By:** S-001-T3

## What
Implement cross-volume-aware file move logic in `crates/core::quarantine`. When the source and destination are on different volumes (different st_dev), perform copy-then-verify-then-remove instead of a direct rename. If verification fails, delete the destination copy and leave the source intact.

## Why
CEO review OV-2: 'Cross-volume quarantine is a new requirement, not a port of Python behavior.' std::fs::rename fails with EXDEV across volumes (external drives vs internal SSD). Without this, quarantining a photo from an external USB drive to the internal quarantine folder would silently fail or panic.

## Context
Volume detection: compare st_dev of source and destination parent directory.
```rust
use std::os::unix::fs::MetadataExt;
let src_dev = std::fs::metadata(source)?.dev();
let dst_dev = std::fs::metadata(dest_parent)?.dev();
let cross_volume = src_dev != dst_dev;
```

Happy path (same volume): std::fs::rename(source, dest)
Cross-volume path: std::fs::copy(source, dest) → verify SHA-256 of dest matches stored hash → std::fs::remove_file(source)
If copy succeeds but verify fails: remove the destination copy, preserve source, return Err(VerifyFailed)

The op_journal records cross_volume=1 for cross-volume moves (schema field already defined in T-004).

This is a PURE LOGIC module — no Tauri, no UI. The Tauri command layer (T-021) calls this.

## How

**Step 1 — Create the quarantine module:**
File: `crates/core/src/quarantine.rs`
```rust
use std::path::{Path, PathBuf};
use std::os::unix::fs::MetadataExt;
use anyhow::{bail, Context, Result};
use crate::hash::sha256_file;

#[derive(Debug)]
pub struct MoveResult {
    pub dest_path: PathBuf,
    pub cross_volume: bool,
}

/// Move source to dest. Uses rename for same-volume, copy+verify+remove for cross-volume.
pub fn move_file(source: &Path, dest: &Path, expected_sha256: &[u8]) -> Result<MoveResult> {
    let src_dev = std::fs::metadata(source)
        .context('stat source')?
        .dev();
    let dest_parent = dest.parent().unwrap_or(dest);
    std::fs::create_dir_all(dest_parent)?;
    let dst_dev = std::fs::metadata(dest_parent)
        .context('stat dest parent')?
        .dev();

    let cross_volume = src_dev != dst_dev;

    if cross_volume {
        move_cross_volume(source, dest, expected_sha256)?;
    } else {
        std::fs::rename(source, dest).context('rename')?;
    }

    Ok(MoveResult { dest_path: dest.to_path_buf(), cross_volume })
}

fn move_cross_volume(source: &Path, dest: &Path, expected_sha256: &[u8]) -> Result<()> {
    std::fs::copy(source, dest).context('copy to dest')?;

    let dest_hash = sha256_file(dest).context('hash dest')?;
    if dest_hash.as_slice() != expected_sha256 {
        // Verification failed — remove the bad copy, preserve source
        let _ = std::fs::remove_file(dest);
        bail!('cross-volume copy verification failed: hash mismatch');
    }

    std::fs::remove_file(source).context('remove source after verified copy')?;
    Ok(())
}
```

```rust
/// Returns dest with suffix if dest already exists: IMG_001.jpg → IMG_001_2.jpg
pub fn collision_safe(dest: &Path) -> PathBuf {
    if !dest.exists() { return dest.to_path_buf(); }
    let stem = dest.file_stem().unwrap_or_default().to_string_lossy();
    let ext = dest.extension().map(|e| format!('.{}', e.to_string_lossy())).unwrap_or_default();
    let parent = dest.parent().unwrap_or(Path::new('.'));
    for n in 2.. {
        let candidate = parent.join(format!('{stem}_{n}{ext}'));
        if !candidate.exists() { return candidate; }
    }
    unreachable!()
}
```

```rust
use std::path::Path;
use anyhow::Result;

/// Returns 32-byte SHA-256 of file contents.
pub fn sha256_file(path: &Path) -> Result<Vec<u8>> {
    use std::io::Read;
    use sha2::{Sha256, Digest};
    let mut file = std::fs::File::open(path)?;
    let mut hasher = Sha256::new();
    let mut buf = [0u8; 65536];
    loop {
        let n = file.read(&mut buf)?;
        if n == 0 { break; }
        hasher.update(&buf[..n]);
    }
    Ok(hasher.finalize().to_vec())
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use tempfile::tempdir;
    use std::fs;

    #[test]
    fn same_volume_rename() {
        let dir = tempdir().unwrap();
        let src = dir.path().join('src.txt');
        let dst = dir.path().join('dst.txt');
        fs::write(&src, b'hello').unwrap();
        let sha = sha256_file(&src).unwrap();
        let r = move_file(&src, &dst, &sha).unwrap();
        assert!(!r.cross_volume);
        assert!(!src.exists());
        assert!(dst.exists());
    }

    #[test]
    fn cross_volume_hash_mismatch_preserves_source() {
        // Simulate mismatch by passing wrong expected hash
        let dir = tempdir().unwrap();
        let src = dir.path().join('src.txt');
        let dst = dir.path().join('subdir/dst.txt');
        fs::write(&src, b'hello').unwrap();
        // Pass wrong hash to trigger mismatch on same-volume copy simulation
        // NOTE: actual cross-volume test requires two mount points; this tests the
        // hash-mismatch branch via a forced wrong hash
        let wrong_hash = vec![0u8; 32];
        // Can't easily force cross-volume in CI; test via move_cross_volume directly
        let result = crate::quarantine::move_cross_volume(&src, &dst, &wrong_hash);
        assert!(result.is_err());
        assert!(src.exists(), 'source must be preserved on hash mismatch');
        assert!(!dst.exists(), 'bad dest copy must be cleaned up');
    }
}
```
