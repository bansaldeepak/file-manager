# native-desktop/S-001-T23: Rapid-click protection on quarantine confirm button

**Status:** pending
**Priority:** P2
**Blocked By:** S-001-T21

## What
Disable the quarantine confirm button immediately after the first click, and re-enable it only after the quarantine operation resolves (success or error). This prevents double-quarantine of the same files from rapid double-clicks.

## Why
CEO review Section 4 WARNING: 'Double-click/rapid-confirm on quarantine action not specified. Must disable the confirm button after first click.' DESIGN.md component spec: 'Rapid double-click protected: button disabled after first click until operation resolves (T4).' Without this, a fast double-click submits the quarantine command twice, potentially erroring on the second call or leaving corrupted journal state.

## Context
DESIGN.md button primary spec: 'Button primary (vermillion): Quarantine action... Rapid double-click protected: button disabled after first click until operation resolves (T4).'

The quarantine confirm button in the inspector panel is the only place this applies. The 'Delete permanently' button (destructive, in the Quarantine view, not main review flow) should have a separate confirmation step — not in scope here.

Implementation: use a `loading` state on the button, set to true on click, false when the async operation settles.

## How

**Step 1 — Create a QuarantineButton component:**
File: `src/components/QuarantineButton.tsx`
```tsx
import React, { useState } from 'react';
import './QuarantineButton.css';

interface QuarantineButtonProps {
  onConfirm: () => Promise<void>;
  disabled?: boolean;
  label?: string;
}

export function QuarantineButton({ onConfirm, disabled, label = 'Quarantine' }: QuarantineButtonProps) {
  const [pending, setPending] = useState(false);

  const handleClick = async () => {
    if (pending || disabled) return;  // extra guard against concurrent calls
    setPending(true);
    try {
      await onConfirm();
    } finally {
      setPending(false);  // always re-enable, even on error
    }
  };

  return (
    <button
      className='quarantine-button'
      onClick={handleClick}
      disabled={pending || disabled}
      aria-busy={pending}
      aria-label={pending ? 'Quarantining...' : label}
    >
      {pending ? (
        <span className='quarantine-button-spinner' aria-hidden />
      ) : null}
      {pending ? 'Moving...' : label}
    </button>
  );
}
```

**Step 2 — Write a test for rapid-click protection:**
File: `src/components/QuarantineButton.test.tsx`
```tsx
import { render, fireEvent, act } from '@testing-library/react';
import { QuarantineButton } from './QuarantineButton';

test('prevents double-fire on rapid clicks', async () => {
  let callCount = 0;
  const slowConfirm = () => new Promise<void>(resolve => {
    callCount++;
    setTimeout(resolve, 100);
  });

  const { getByRole } = render(<QuarantineButton onConfirm={slowConfirm} />);
  const button = getByRole('button');

  // Rapid double click
  fireEvent.click(button);
  fireEvent.click(button);  // button should be disabled after first click

  await act(() => new Promise(r => setTimeout(r, 200)));

  expect(callCount).toBe(1);  // only one call despite two clicks
});

test('re-enables after operation completes', async () => {
  const confirm = vi.fn().mockResolvedValue(undefined);
  const { getByRole } = render(<QuarantineButton onConfirm={confirm} />);
  const button = getByRole('button');

  await act(async () => { fireEvent.click(button); });

  expect(button).not.toBeDisabled();  // re-enabled after async resolve
});
```
