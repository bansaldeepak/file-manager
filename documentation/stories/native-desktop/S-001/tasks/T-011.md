# native-desktop/S-001-T11: Implement core::scanner: walkdir, size filter, prehash, SHA-256, pixel hash, SQLite cache

**Status:** done
**Priority:** P0
**Blocked By:** S-001-T7

## What
Implement the full scanner pipeline in `crates/core::scanner`: walk a directory tree, filter by size (skip zero-byte and >500MB), compute 4KB prehash to eliminate non-duplicates cheaply, compute full SHA-256 for candidate pairs, compute pixel hash for image files, and write results to the SQLite file_cache via crate:index.

## Why
This is the main Stage 2 deliverable. Without a working scanner, there is nothing to show in the UI. T-007 proved the hash algorithms match Python; this task wires them into a real scanner that handles the full 30K-image case.

## Context
Python reference scanner (app.py:lines 42-200 approx):
- SHA-256: read file in 64KB chunks, skip on IOError, store 0-size files
- Pixel hash: only for image extensions (.jpg, .jpeg, .png, .heic, .heif, .webp, .tiff, .bmp)
- Keeper ordering: resolution DESC, size DESC, path ASC (no EXIF date in Rust MVP — add post-MVP)
- Group building: files with same SHA-256 form exact-duplicate groups; files with same pixel_hash (but different SHA-256) form pixel-identical groups

Connected-component grouping behavior: file A and B share SHA-256 → one group. File B and C share pixel_hash → same group (transitivity).

CEO review D2: scanner lives in crate:core, SQLite writes via crate:index (file_cache module from T-009).
CEO review E8: pixel hash decoding uses the semaphore from T-005 (max 2-4 concurrent decodes).
CEO review T1/T-008: pixel hash for oversized images returns Err → store error string in file_cache.error, skip pixel group.

WebP thumbnail generation (D6): generate during scan, cache as `<hash>.webp` in AppData. This is a separate sub-step within the scanner.

**Step 1 — Create scanner module:**

```rust
use std::path::{Path, PathBuf};
use anyhow::Result;
use walkdir::WalkDir;
use rayon::prelude::*;
use tracing::{info, debug, warn};
use crate::{hash, pixel_hash, decode_semaphore};

const MIN_FILE_SIZE: u64 = 1;
const MAX_FILE_SIZE: u64 = 500 * 1024 * 1024; // 500MB

static IMAGE_EXTENSIONS: &[&str] = &[
    'jpg', 'jpeg', 'png', 'heic', 'heif', 'webp', 'tiff', 'tif', 'bmp',
];

#[derive(Debug)]
pub struct ScannedFile {
    pub path: PathBuf,
    pub size: u64,
    pub mtime_ns: i64,
    pub sha256: Option<[u8; 32]>,
    pub pixel_hash: Option<[u8; 32]>,
    pub error: Option<String>,
}

pub fn scan_directory(root: &Path, progress: impl Fn(usize) + Send + Sync) -> Result<Vec<ScannedFile>> {
    let entries: Vec<PathBuf> = WalkDir::new(root)
        .follow_links(false)
        .into_iter()
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_file())
        .map(|e| e.path().to_path_buf())
        .collect();

    info!('Found {} files in {}', entries.len(), root.display());

    let results: Vec<ScannedFile> = entries.par_iter().enumerate().map(|(i, path)| {
        progress(i);
        scan_file(path)
    }).collect();

    Ok(results)
}

fn scan_file(path: &Path) -> ScannedFile {
    let meta = match std::fs::metadata(path) {
        Ok(m) => m,
        Err(e) => return ScannedFile {
            path: path.to_path_buf(),
            size: 0, mtime_ns: 0,
            sha256: None, pixel_hash: None,
            error: Some(format!('stat failed: {e}')),
        },
    };

    let size = meta.len();
    let mtime_ns = meta.modified()
        .ok()
        .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
        .map(|d| d.as_nanos() as i64)
        .unwrap_or(0);

    if size < MIN_FILE_SIZE || size > MAX_FILE_SIZE {
        return ScannedFile {
            path: path.to_path_buf(), size, mtime_ns,
            sha256: None, pixel_hash: None,
            error: Some(format!('size {size} out of range')),
        };
    }

    let sha256 = match hash::sha256_file(path) {
        Ok(h) => Some(h),
        Err(e) => return ScannedFile {
            path: path.to_path_buf(), size, mtime_ns,
            sha256: None, pixel_hash: None,
            error: Some(format!('hash failed: {e}')),
        },
    };

    let is_image = path.extension()
        .and_then(|e| e.to_str())
        .map(|e| IMAGE_EXTENSIONS.contains(&e.to_lowercase().as_str()))
        .unwrap_or(false);

    let (pixel_hash_val, pixel_err) = if is_image {
        match pixel_hash::compute(path) {
            Ok(h) => (Some(h), None),
            Err(e) => {
                warn!('pixel hash failed for {}: {e}', path.display());
                (None, Some(e.to_string()))
            }
        }
    } else {
        (None, None)
    };

    ScannedFile {
        path: path.to_path_buf(),
        size, mtime_ns,
        sha256,
        pixel_hash: pixel_hash_val,
        error: pixel_err,
    }
}
```

**Step 2 — Create grouper module:**
File: `crates/core/src/grouper.rs`
```rust
use std::collections::HashMap;
use crate::scanner::ScannedFile;

#[derive(Debug)]
pub struct DuplicateGroup {
    pub group_id: usize,
    pub match_type: MatchType,
    pub keeper: usize,    // index into files
    pub files: Vec<usize>, // indices into the global file list
}

#[derive(Debug, Clone, PartialEq)]
pub enum MatchType { Exact, PixelIdentical }

pub fn build_groups(files: &[ScannedFile]) -> Vec<DuplicateGroup> {
    let mut sha256_groups: HashMap<Vec<u8>, Vec<usize>> = HashMap::new();
    let mut pixel_groups: HashMap<Vec<u8>, Vec<usize>> = HashMap::new();

    for (i, f) in files.iter().enumerate() {
        if let Some(h) = &f.sha256 {
            sha256_groups.entry(h.to_vec()).or_default().push(i);
        }
        if let Some(h) = &f.pixel_hash {
            pixel_groups.entry(h.to_vec()).or_default().push(i);
        }
    }

    let mut groups = Vec::new();
    let mut group_id = 0;

    for (_, members) in sha256_groups.iter().filter(|(_, v)| v.len() > 1) {
        let keeper = pick_keeper(files, members);
        groups.push(DuplicateGroup { group_id, match_type: MatchType::Exact, keeper, files: members.clone() });
        group_id += 1;
    }
    for (_, members) in pixel_groups.iter().filter(|(_, v)| v.len() > 1) {
        let keeper = pick_keeper(files, members);
        groups.push(DuplicateGroup { group_id, match_type: MatchType::PixelIdentical, keeper, files: members.clone() });
        group_id += 1;
    }
    groups
}

fn pick_keeper(files: &[ScannedFile], indices: &[usize]) -> usize {
    // Keeper ordering: size DESC, path ASC (no EXIF date in Rust MVP)
    *indices.iter().max_by_key(|&&i| {
        let f = &files[i];
        (f.size, std::cmp::Reverse(f.path.to_string_lossy().to_string()))
    }).unwrap()
}
```

use dedupe_core::scanner::scan_directory;
use dedupe_core::grouper::build_groups;

#[test]
fn scan_fixture_dir_finds_duplicates() {
    let fixtures = Path::new(concat!(env!('CARGO_MANIFEST_DIR'), '/../../tests/fixtures/images'));
    if !fixtures.exists() { return; }
    let files = scan_directory(fixtures, |_| {}).unwrap();
    assert!(!files.is_empty(), 'expected at least one file');
    let groups = build_groups(&files);
    // byte-identical copy should form an exact group

        'expected at least one exact duplicate group');
}
