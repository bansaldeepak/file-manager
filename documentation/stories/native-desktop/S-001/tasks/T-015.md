# native-desktop/S-001-T15: Persistent search bar (Cmd+F) in toolbar — DD2

**Status:** pending
**Priority:** P1
**Blocked By:** S-001-T14

## What
Add a persistent, always-visible search bar in the toolbar area of the AppShell. It should be activated by Cmd+F and max-width 280px toward the right side of the toolbar per DESIGN.md. Filtering the contact sheet by filename is the primary use case.

## Why
Design decision DD2: 'Persistent header search — always visible in toolbar, max-width 280px, toward the right.' The Python Streamlit app has no search. This was a top-tier UX ask across all 3 reviews. A search that requires clicking a button first fails the 'visible evidence' principle.

## Context
DESIGN.md toolbar spec:
- Toolbar: 52px height
- 'Persistent search per DD2, max-width 280px toward the right'
- Input style: borderColor var(--color-text-muted), rounded var(--radius-sm) = 4px
- Search shortcut: Cmd+F (registered in T-018 keyboard shortcuts task)

The search bar emits a filter value upward via a callback prop. The contact sheet component (built in a later task) will consume this filter. For this task, just wire up the component and confirm it renders and accepts input.

## How

**Step 1 — Create SearchBar component:**
File: `src/components/SearchBar.tsx`
```tsx
import React, { useRef, useEffect } from 'react';
import './SearchBar.css';

interface SearchBarProps {
  value: string;
  onChange: (value: string) => void;
  focusRef?: React.RefObject<HTMLInputElement>;
}

export function SearchBar({ value, onChange, focusRef }: SearchBarProps) {
  const inputRef = focusRef ?? useRef<HTMLInputElement>(null);

  return (
    <div className='search-bar'>
      <svg className='search-icon' width='14' height='14' viewBox='0 0 14 14' aria-hidden>
        <circle cx='6' cy='6' r='4.5' stroke='currentColor' strokeWidth='1.5' fill='none'/>
        <line x1='9.5' y1='9.5' x2='13' y2='13' stroke='currentColor' strokeWidth='1.5' strokeLinecap='round'/>
      </svg>
      <input
        ref={inputRef}
        type='search'
        placeholder='Search'
        value={value}
        onChange={e => onChange(e.target.value)}
        className='search-input'
        aria-label='Search files'
      />
      {value && (
        <button className='search-clear' onClick={() => onChange('')} aria-label='Clear search'>
          ×
        </button>
      )}
    </div>
  );
}
```
