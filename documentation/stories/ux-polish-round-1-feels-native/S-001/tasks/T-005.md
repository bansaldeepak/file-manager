# ux-polish-round-1-feels-native/S-001-T5: Thumbnail loading shimmer

**Status:** pending
**Priority:** P1
**Blocked By:** —

## Description

DESIGN.md interaction table lists "Placeholder shimmer" for thumbnail loading state. Currently, thumbnails show nothing (or a blank gray box) while loading. Add a CSS shimmer animation for the loading placeholder.

## Files to modify

### `frontend/src/styles/tokens.css`

Add a shimmer keyframe animation at the end of the file (before any media query):

\`\`\`css
@keyframes shimmer {
  0% { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}
\`\`\`

### `frontend/src/components/ContactSheet.css`

The keeper card thumb already has a background color for the loading state (line 225: \`.keeper-card-thumb-wrap\`). Add a shimmer class. After \`.keeper-card-thumb\` (line ~233), add:

\`\`\`css
.keeper-card-thumb[src=""],
.keeper-card-thumb:not([src]) {
  visibility: hidden;
}

.keeper-card-thumb-wrap:has(.keeper-card-thumb[src=""], .keeper-card-thumb:not([src])) {
  background: linear-gradient(
    90deg,
    color-mix(in srgb, var(--color-text) 4%, transparent) 25%,
    color-mix(in srgb, var(--color-text) 8%, transparent) 50%,
    color-mix(in srgb, var(--color-text) 4%, transparent) 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;
}
\`\`\`

Note: The \`:has()\` selector approach may not work because the thumbnail src is set by useThumbnail hook. A simpler approach:

### Alternative — use the existing loading state in useThumbnail

Look at how \`useThumbnail\` works. The \`src\` returned is \`undefined\` until loaded. In \`ContactSheet.tsx\` the \`<img>\` always renders with \`src={src}\` — when \`src\` is undefined, the img shows nothing.

Better approach: In \`ContactSheet.tsx\` \`KeeperCard\` component (line ~173-184), wrap the img in a conditional like QuarantineView already does (line 69-73):

\`\`\`tsx
{src ? (
  <img className="keeper-card-thumb" src={src} ... />
) : (
  <div className="keeper-card-thumb keeper-card-thumb--shimmer" 
       style={{ width: thumbnailSize, height: thumbnailSize }} />
)}
\`\`\`

Then add CSS:
\`\`\`css
.keeper-card-thumb--shimmer {
  background: linear-gradient(
    90deg,
    color-mix(in srgb, var(--color-text) 4%, transparent) 25%,
    color-mix(in srgb, var(--color-text) 8%, transparent) 50%,
    color-mix(in srgb, var(--color-text) 4%, transparent) 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;
}
\`\`\`
