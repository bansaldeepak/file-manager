# ux-polish-round-1-feels-native/S-001-T1: Title bar drag region

**Status:** pending
**Priority:** P1
**Blocked By:** —

## Description

Add `data-tauri-drag-region` to the toolbar so the macOS window can be dragged by grabbing the toolbar area. This is a basic native app expectation.

## Files to modify

- `frontend/src/components/AppShell.tsx` — line 33: add `data-tauri-drag-region` attribute to the `.toolbar` div
- `frontend/src/components/AppShell.css` — add `-webkit-app-region: drag` to `.toolbar`, and `-webkit-app-region: no-drag` to interactive children (`.toolbar-right`, `TabBar` buttons) so they remain clickable

## Implementation

In `AppShell.tsx:33`, change:
```tsx
<div className="toolbar">
```
to:
```tsx
<div className="toolbar" data-tauri-drag-region>
```

In `AppShell.css`, add to `.toolbar`:
```css
-webkit-app-region: drag;
```

Add a new rule:
```css
.toolbar button,
.toolbar input,
.toolbar a,
.toolbar-right {
  -webkit-app-region: no-drag;
}
```

## Verify

Build and run. Drag the window by clicking empty toolbar space. Verify tabs and search still respond to clicks.
