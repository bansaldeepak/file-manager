## Decision

Quick Look spike: qlmanage -p is viable from Tauri 2 on macOS

## Context

## Context
D5 (user-approved) adds macOS Quick Look integration for full-size image previews. OV-6 flagged that QLPreviewPanel may need Objective-C bridging, which could be complex or blocked by the Tauri sandbox.

## Spike Findings

### Approach investigated
Used `qlmanage -p <file>` as the CLI proxy for Quick Look rather than direct QLPreviewPanel Objective-C bindings.

### Results

**qlmanage availability:** `/usr/bin/qlmanage` is present on all standard macOS installations.

**Sandbox compatibility:** `qlmanage` is a system binary that runs as a separate process. Tauri's sandbox allows `std::process::Command` to spawn system binaries. No additional entitlements required beyond the existing `fs:allow-home-read-recursive` for reading the file path.

**Invocation:** `qlmanage -p /path/to/image.jpg` opens the native Quick Look floating panel. The caller's process returns immediately (qlmanage runs as a detached system service). Works for HEIC, JPEG, PNG, RAW (via macOS-installed codecs), and video formats — the full Quick Look codec stack.

**QLPreviewPanel via objc2:** NOT needed for this use case. The objc2 approach would be required only if we need to control the panel's position, parent window, or lifecycle from within the app. For a 'press spacebar to preview' UX, qlmanage is sufficient and avoids objc2 dependency complexity.

## Decision
Use `qlmanage -p <path>` via `std::process::Command` for Quick Look integration. The `quicklook_spike.rs` module is already wired into the `preview_file` Tauri command. Full implementation (T-013 follow-through) connects spacebar keyboard shortcut in the frontend to this command.

## Not needed
- `objc2` crate dependency
- `objc2-quartz-core` dependency
- Additional macOS entitlements beyond existing fs permissions

## Fallback
If qlmanage is unavailable (non-macOS or future macOS change): `open -R <file>` reveals the file in Finder. This fallback is already expressible in the same code path.
