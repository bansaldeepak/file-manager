## Vision

### 10x Check

The current app scans 30K images in ~43 seconds for visual grouping and runs in a browser tab that requires a terminal + venv. The native app targets cached folder opens under 500ms, keyboard-driven review, and a double-clickable .app. For a tool used repeatedly on a personal photo library, the difference between "open terminal, activate venv, run streamlit, wait for browser" and "double-click, press a key, review" is the difference between a chore and a tool you actually use. That's 10x in practice, even if the raw scan speed improvement is 2-5x.

### Platonic Ideal (SELECTIVE -- targeted additions only)

The best version of this app opens instantly, shows your photo library organized by duplicate coverage, lets you review and clean up with keyboard shortcuts, and never loses a file. Quick Look previews (spacebar), drag-and-drop folder selection, and WebP-cached thumbnails bring it closer to that ideal without inflating the scope.
